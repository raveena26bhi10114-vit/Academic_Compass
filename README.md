# Academic Compass: Student Schedule, Assignment and Progress Tracking System

## Project Description

Academic Compass is a Python-based student academic tracking system designed to help students organize their academic activities and monitor their progress.

## Objectives

- To help students manage their academic schedules.
- To track assignments and their status.
- To monitor study progress.
- To calculate CGPA based on grade points.

## Features

### 1. Timetable
Allows students to enter and view their class timetable.

### 2. Assignment Tracker
Allows students to enter assignment details and track their assignment status.

### 3. Study Progress
Allows students to enter completed and total topics and calculates their study progress percentage.

### 4. CGPA Calculator
Calculates the CGPA based on the grade points entered for different subjects.

### 5. Exit
Allows the user to safely exit the program.

## Technologies Used

- Python
- Python IDLE

## Project Modules

- main.py
- timetable.py
- assignment_tracker.py
- study_progress.py
- cgpa_calculator.py
